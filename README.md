# Эмулятор оболочки ОС

Учебный проект по дисциплине «Конфигурационное управление» (вариант 26).
Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом.

## 1. Общее описание

Программа открывает окно с областью вывода и строкой ввода. Пользователь
вводит команды, эмулятор разбирает их (с учётом кавычек) и выполняет.
Заголовок окна строится из реальных данных ОС: `Эмулятор - [user@host]`.

Реализовано на Python 3.10+ (только стандартная библиотека, GUI - tkinter).

## 2. Описание всех функций и настроек

### Команды

- `ls [args]` - Заглушка: печатает своё имя и аргументы
- `cd [args]` - Заглушка: печатает своё имя и аргументы
- `exit` - Закрывает эмулятор

### Разбор команд

- Слова разделяются пробелами.
- Кавычки `"..."` и `'...'` объединяют слова в один аргумент.
- `\` экранирует следующий символ (кроме одинарных кавычек).
- Ошибки: `command not found` для неизвестной команды,
  `syntax error: ...` для незакрытой кавычки.

## 3. Сборка и запуск тестов

Сборка не требуется. Установка инструментов разработки:

```
pip install -r requirements-dev.txt
```

Запуск эмулятора:

```
./run.sh          (Linux / macOS)
run.bat           (Windows)
```

Запуск тестов и проверка стиля:

```
python -m pytest
python -m flake8 src tests
```

## 4. Примеры использования

```
user@host$ ls -l "my documents"
ls: args=['-l', 'my documents']
user@host$ cd 'a b' c
cd: args=['a b', 'c']
user@host$ foo
foo: command not found
user@host$ ls "abc
syntax error: unterminated quote
user@host$ exit
```
